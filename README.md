# REST with Spring Boot and Java

API REST desenvolvida com Java e Spring Boot, com o objetivo de praticar e aprofundar conhecimentos em desenvolvimento Back-end, construção de APIs REST e persistência de dados.

O projeto consiste no desenvolvimento de uma API para gerenciamento de pessoas (*Person*), utilizando Spring Data JPA e MySQL para comunicação e armazenamento das informações.

Atualmente, o projeto está em desenvolvimento e receberá novas funcionalidades, correções e melhorias ao longo do tempo.

## Tecnologias utilizadas

- Java 25
- Spring Boot 4
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Conceitos aplicados

- Desenvolvimento de APIs REST.
- Manipulação de requisições HTTP.
- Conversão e manipulação de dados JSON.
- Persistência de dados com JPA e Hibernate.
- Integração com banco de dados MySQL.
- Mapeamento de entidades com JPA.
- Utilização de anotações do Spring Framework.

## Próximas melhorias

Como o projeto ainda está em desenvolvimento, algumas implementações passarão por refatorações e aprimoramentos.

- Substituir o uso genérico de `@RequestMapping` por anotações específicas, como `@GetMapping`, `@PostMapping`, `@PutMapping` e `@DeleteMapping`.
- Aprimorar a organização e separação de responsabilidades entre as camadas.
- Implementar validações de dados nas requisições.
- Melhorar o tratamento de exceções e padronizar as respostas da API.
- Aprimorar as operações de CRUD.
- Implementar testes automatizados.
- Melhorar a documentação dos endpoints.

## Status do projeto

Este repositório acompanha minha evolução prática com Java e Spring Boot. Novas funcionalidades, correções e melhorias serão adicionadas progressivamente.
